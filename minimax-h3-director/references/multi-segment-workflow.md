# 多段生成长片工作流（Multi-Segment Workflow）

适用：目标成片超过 H3 单次上限（15s），需拆成多段独立生成再剪辑拼接；或用户没有参考图、需要先规划资产。核心目标：**切点两侧方向一致，不南辕北辙**。

## 0. 前置资产规划（用户无参考图时先做）

1. 先判断需要哪些参考图，再写生图提示词：
   - **场景图**（正常底）：环境/地点全景，作首帧（I2VA）或全片场景锁。
   - **物品图**（白底）：单个道具/物体的干净参考，作身份锁；提示词写"只取物体身份、忽略背景"，负面清单加"不要白/黑背景色块"。
   - **发光元素图**（黑底）：光效/粒子/发光体，黑底才能读出辉光。
2. 每张图标注：**H3 用途**（首帧 / 场景锁 / 身份锁 / 构图锁）+ **画幅一致性**（首帧图画幅=成片画幅；I2VA 跟随图片比例，不再另设 aspect_ratio）。
3. 参考图只挂"本段画面里实际出现的元素"，不提前挂下一段才登场的元素；跨段只共享场景锁。
4. **生图提示词一律路由到 zy-cinematic-realism skill**：先调用 Skill 工具加载 zy-cinematic-realism（`~/.workbuddy/skills/zy-cinematic-realism/SKILL.md`），按其工作流产出（电影写实单帧法：动机光、物理场景、去 AI 感）；本文件只负责资产清单、H3 用途与画幅规划，**不自行写生图提示词**。

## 1. 分段方案（生成前先定）

- 按叙事节拍切段，每段 4–15s；同段内动作过多就拆细。
- 给出主方案 + 降级路径：
  - **主方案**：长段少切（如 2×15s），电影感强但单段动作密度高、风险高。
  - **降级**：短段多切（如 5×6s），每镜一动作更稳，切点变多但景别跨度大更能掩错。
- 每段提示词内：时间戳连续无 gap/overlap；一镜一运镜；关键动作留足时间（高潮/转折/结局 ≥4s 独立时间窗，别塞进最后 2–3 秒）。

## 2. 跨段衔接手段（默认走 2→3→4；尾帧续接仅用户点名才用）

> **用户偏好默认**：尾帧续接只在用户明确要求时使用，**默认不主动推荐**，默认路径为下面的 2/3/4。

1. **尾帧续接（可选增强，仅用户点名时用）**：上一段生成后，导出其**末帧**（单图，最轻量、比例跟随原图）或**整段视频**（可继承运动/光，总时长 ≤15s）作为下一段参考素材，声明用途："上一段结尾帧——本段从这一帧的画面继续，构图、机位、光线、主体位置与之一致，仅在此基础上发生以下变化…"。下一段提示词**只写变化**（动作/运镜/声音），不重述帧里已有的外观（I2VA 原则）。两段运镜方向相反（推近→后拉）时，尾帧续接让切点变成"同一位置换运镜"，连贯性最好。
2. **文字设计（无尾帧可传时）**：禁止"同帧镜像"（本段结尾=下段开头、同一景别同一构图——两段独立生成不可能像素对齐，同构图硬切像卡顿/倒放）。正确三件套：① **景别不同**——前段收近景、后段起中景（更远/不同重新取景）；② **动作匹配**——切点两侧同一动态主体同一运动方向跨切点；③ **共享场景锁**——两段挂同一张场景参考图。
3. **机位与空间词统一**：两段"运镜"行写同一机位高度/角度与同一空间语言（如"观众席前排低角度""向舞台上空聚拢"）。
4. **剪辑兜底（保底）**：验收三点——切点方向一致、关键动作一眼可读、色调统一（色轮微调）；残差用 2–4 帧叠化或错位 2–3 帧（J-cut）掩盖。

其他硬规则：
- **结尾别"停住"**：前段在动势中收尾（运动没停），切点即"正在发生的瞬间"；静止收尾放大差异。
- **每段参考图组合模板**：`挂图清单 = 尾帧续接/首帧 + 场景锁 + 本段出现元素锁`，每张图注明用途。

## 3. 无音乐 / 后期配乐模式

- 用户后期自己配乐时：声音层只写**环境声 + 物理音效**（琴键/碰撞/落物/气流声——同时是后期配乐的"节拍器"）。
- 负面清单写死：无任何音乐、旋律、配乐、人声哼唱（`non_diegetic_music: N/A` 只管背景乐，画面内 diegetic 旋律仍会被生成，必须显式禁掉）。
- 交付时附**配乐对齐点表**：关键动作的胶片时间（如"第一枚琴键 4–8s / 顶点 15–19s / 骤停 19–22s"），供后期把旋律对准动作。

## 4. 生成后验收清单

- [ ] 切点两侧运动方向一致（无"镜头重来一遍"感）
- [ ] 关键动作一眼可读（高潮/转折/结局未压缩成一闪而过）
- [ ] 两段色调统一（偏色用色轮微调）
- [ ] 若使用了尾帧续接：下一段已声明"从上一段结尾帧继续"（未点名使用则跳过此项）
- [ ] 白/黑底物品参考未泄漏底色（负面清单含"不要白/黑背景色块"）
